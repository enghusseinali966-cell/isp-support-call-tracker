# ISP Support Call Tracker

نظام ويب لإدارة بلاغات ومكالمات دعم مزود الإنترنت.

## المزايا
- حساب Admin وحسابات Agents متعددة.
- الأدمن يشاهد كل البلاغات ويُنشئ/يوقف حسابات Agents.
- الـAgent يشاهد بلاغاته فقط.
- تسجيل رقم المشترك ووصف المشكلة ورمز الحل والحل والحالة.
- حالات البلاغ: Open / Closed / Unresolved.
- بحث وتصفية وتصدير CSV.
- قاعدة بيانات PostgreSQL عند النشر، وSQLite للتجربة المحلية.

## التشغيل محلياً على Windows
1. ثبّت Python 3.11 أو أحدث.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   set SECRET_KEY=ضع_قيمة_طويلة_وسرية
   set ADMIN_USERNAME=admin
   set ADMIN_PASSWORD=كلمة_مرور_قوية_هنا
   flask --app app init-db
   python app.py
   ```
4. افتح `http://127.0.0.1:5000`.

## النشر على Render
1. ارفع هذا المجلد إلى مستودع GitHub خاص (Private).
2. أنشئ قاعدة PostgreSQL على Neon (الخطة المجانية) وخذ رابط الاتصال `DATABASE_URL` بصيغة PostgreSQL. لا تستخدم قاعدة Render المجانية لحفظ بيانات دائمة لأنها تنتهي بعد 30 يوماً.
3. في Render اختر **New → Web Service** واربط مستودع GitHub.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `gunicorn app:app`
6. أضف Environment Variables:
   - `SECRET_KEY`: قيمة عشوائية طويلة وسرية.
   - `DATABASE_URL`: رابط PostgreSQL.
   - `ADMIN_USERNAME`: اسم حساب الأدمن.
   - `ADMIN_PASSWORD`: كلمة مرور قوية (8 أحرف على الأقل).
   - `COOKIE_SECURE`: `true`
7. عند أول تشغيل، ينشئ النظام الجداول وحساب الأدمن تلقائياً من متغيرات البيئة.
8. افتح رابط `onrender.com` وسجّل الدخول بحساب الأدمن.

**مهم بخصوص المجاني:** خدمة Render المجانية تتوقف بعد 15 دقيقة من عدم الاستخدام، وقد تحتاج قرابة دقيقة لتعمل عند أول زيارة. استخدم Neon PostgreSQL المجانية للتخزين (حدودها قابلة للتغيير)، وخذ نسخاً احتياطية دورية. راجع حدود الخطة المجانية قبل اعتمادها لعمل الشركة. لا ترفع ملف `.env` أو كلمات المرور إلى GitHub.

## الأمان
- غيّر SECRET_KEY وكلمة مرور الأدمن قبل النشر.
- لا تشارك بيانات الدخول في المحادثات.
- فعّل HTTPS من الاستضافة.
- خذ نسخاً احتياطية منتظمة من قاعدة البيانات.
- هذا إصدار أولي؛ قبل استخدامه لبيانات حساسة أو تشغيل شركة فعلياً، يلزم اختبار أمني ومراجعة صلاحيات ونسخ احتياطي.
